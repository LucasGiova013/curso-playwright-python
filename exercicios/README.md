# Exercícios sugeridos

1. Testar a inclusão de duas tarefas e sua ordem.
2. Verificar que uma tarefa vazia não é adicionada.
3. Implementar um botão de exclusão e testar o comportamento.
4. Explorar o trace de um teste que falhou.
5. Instalar Firefox e executar a suíte com `pytest --browser firefox`.
